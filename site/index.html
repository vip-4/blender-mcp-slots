Blender MCP Slots：一套 CONFIG 驱动的多机台老虎机引擎

Blender MCP Slots 是一个用 Node.js 实现的多机台老虎机（SLOT GAMES）引擎与 MCP 服务。新增一台机台只需写一个 CONFIG 文件：转轮条带、赔付表、线制、特性开关全部由配置描述，引擎、MCP 工具与前端无需改动一行代码。

摘要：Blender MCP Slots 是什么？

Blender MCP Slots 是一个开源的多机台老虎机（SLOT GAMES）引擎，通过 Model Context Protocol（MCP）对外提供服务。它把「转轮逻辑、赔率、中奖判定、奖励触发、特殊符号」全部抽象为一份可校验的 CONFIG，目前内置 11 款机台，涵盖免费旋转、雪崩连锁、双向赔付、WILD 重旋、金币重旋与收集符等主流玩法；每款机台都用 20 万轮蒙特卡洛模拟校准 RTP，实测值均落在目标 ±2% 区间内。

引擎实现
Node.js 20+ ESM，零运行时依赖，共享引擎目录 src/games/engine/*。
机台数量
11 款（3×3 到 5×3，5 线 / 10 线 / 20 线 / 243 WAYS）。
配置驱动
新增机台 = 新增一个 CONFIG 文件，重启或调用 slots.reloadConfigs 生效。
公平性
服务端种子 + 客户端种子 + nonce，公开种子哈希，结果可复算。
RTP 校准
slots.simulate 蒙特卡洛，20 万轮/台，实测 0.9386 ~ 0.9679。
许可与用途
MIT 开源，用于引擎/数学/概率教学与技术演示，不涉及任何真实货币。

合规说明：本项目为概率引擎与软件工程示例，所有「投注 / 派彩」均为虚拟积分，不涉及真实货币交易，也不提供任何博彩服务。

引擎能力：CONFIG 即玩法

所有玩法能力都是 CONFIG 开关，机台之间可任意组合，引擎代码不写死任何一款机台。

freeSpins 免费旋转
散射计数触发，可指定独立条带、倍率上限与再触发规则。
cascades 雪崩连锁
中奖格消除 → 上方下落 → 顶部补新符号，倍率阶梯逐段递增，可跨轮累积。
holdAndRespin 金币重旋
N 枚金币触发锁仓重旋，次数重置机制 + 多档奖池。
collect 收集符
指定轴出现收集符即兑现盘面所有金币面值。
multiplierWild 倍率 WILD
WILD 携带 x2/x3/x5/x10 倍率，直接乘入线赢。
expandingSymbol 扩展符号
Book 系玩法：随机选定符号，出现 ≥2 个即整轴展开后结算。
wildRespin WILD 重旋
Starburst 系玩法：WILD 落在指定轴即整轴展开，并赠送 N 次免费重旋。
evaluation.direction = both 双向赔付
同一条线「左→右」与「右→左」各判一次，两向成立各付一次。

常见问题

如何新增一款老虎机机台？

在 src/games/configs/ 下新增一个导出 CONFIG 的 .js 文件，描述盘面、符号与权重、赔付表、线制与特性开关即可。启动时注册表会自动加载并做契约校验（fail-fast）：单份配置出错只会让该机台下线，不影响其它机台与 MCP 服务。运行时也可通过 slots.registerGame 注入或用 slots.reloadConfigs 热重载。

如何校准一款机台的 RTP？

运行 node scripts/simulate.js（或调用 MCP 工具 slots.simulate）对每台机台跑 20 万轮蒙特卡洛，输出实测 RTP、最大单轮倍数与特性触发次数。若偏离目标，用 CONFIG 中的 tuning.payScale 线性微调赔付表；特性叠加导致的结构性失衡（例如雪崩倍率跨轮累积）应调整特性参数而非只调 payScale。

中奖结果是否可以验证公平性？

可以。每轮使用「服务端种子 + 客户端种子 + nonce」派生的可复现随机数，响应中返回 fairness（服务端种子哈希、客户端种子、nonce），可在会话结束后公开服务端种子复算整条结果链。转轮结果先于动画生成，前端只负责演出。

支持哪些赔付判定模式？

支持 lines（固定线制，内置 5/10/20 线等图案）与 ways（243 WAYS 等相邻轴任意位置）两种模式；线制机台还可设置 evaluation.direction = both 启用双向赔付。

是否依赖数据库或外部服务？

核心玩法零外部依赖，可纯内存运行。可选接入 Postgres 做会话与排行榜持久化，接入 Cloudflare R2 做旋转日志归档；两者均带降级开关，不可用时自动降级到内存并标记 degraded，不影响旋转主流程。

如何在生产环境部署？

MCP 服务以 node src/main.js --transport=http --port=5173 启动，通过 /rpc 统一入口提供全部工具；静态站点（当前页面）为自包含单文件，可直接托管到 GitHub Pages、Vercel、Cloudflare Pages 或 EdgeOne Pages。详见下方「部署与集成」。

部署与集成步骤

1. 启动 MCP 服务

git clone https://github.com/vip-4/blender-mcp-slots.git
cd blender-mcp-slots && npm install
node src/main.js --transport=http --port=5173   # 统一入口：POST /rpc

2. 通过统一入口调用

curl -s http://127.0.0.1:5173/rpc -H 'content-type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"slots.spin","params":{"sessionId":"...","bet":1}}'

3. 部署静态站点

  1. GitHub Pages：推送 main 后由 .github/workflows/pages.yml 自动发布 site/ 到 gh-pages 分支。
  2. Cloudflare Pages：npx wrangler pages deploy site --project-name=blender-mcp-slots。
  3. Vercel：npx vercel deploy site --prod（需 VERCEL_TOKEN）。
  4. EdgeOne Pages：单文件 site/index.html 可直接 npx -y mcporter call mcp-on-edge.edgeone.app/mcp-server.deploy-html 发布。

4. 稳定性与可观测性

  1. /healthz 与 MCP 工具 system.health 暴露机台数量、配置故障、活跃会话与存储驱动状态。
  2. 限流、幂等缓存与旋转预算三重护栏；配置契约校验保证坏配置只下线单机台。
  3. 存储与归档均为旁路降级，失败只计数不阻断旋转。
