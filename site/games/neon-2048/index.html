霓虹 2048：免费在线合并益智游戏

霓虹 2048 是 2048 的霓虹主题单文件网页实现：每次移动会随机生成一个新方块，相同数字的方块相撞即合并加倍，目标是拼出 2048。零依赖、离线可玩、无广告、无需注册，支持键盘与触屏滑动。

分数 0 最高 0 步数 0

用方向键或 WASD 开始，手机上直接滑动。

怎么玩（规则一览）

目标
把相同数字的方块合并，最终拼出 2048；拼出后仍可继续冲击更高分。
一次移动
所有方块朝该方向滑动到底，相邻同数字两两合并（每次移动每个方块只合并一次）。
新方块
每次有效移动后随机生成一个方块：90% 概率为 2，10% 概率为 4。
结束条件
棋盘填满且四个方向都无法合并时游戏结束。
计分
每次合并把合并后的数字计入分数，因此越大越晚合并得分越高。

霓虹 2048 的键盘与触屏操作
操作键盘触屏 / 鼠标

新开一局R点击「新游戏」
撤销Z点击「撤销一步」

高分技巧

固定最大块
把最大数字固定在某个角落，避免它来回搬家导致棋盘碎裂。
单向优先
优先使用两个方向（如左、下），第三个方向只在必要时用，能保持棋盘有序。
留空列
始终保持至少一列/一行是空的，给新方块与合并留缓冲。
