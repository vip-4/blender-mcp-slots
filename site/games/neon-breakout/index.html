霓虹打砖块：免费在线网页版 Breakout

霓虹打砖块是打砖块（Breakout）的霓虹主题单文件网页实现：移动挡板反弹小球，击碎全部砖块即可通关，三条命用完即结束。零依赖、离线可玩、无广告、无需注册，支持鼠标、键盘与触屏。

分数 0 生命 3 剩余砖块 0 最高 0

点击「开始」，用鼠标、方向键或手指拖动挡板。

怎么玩（规则一览）

目标
用挡板把小球弹回上方，击碎全部砖块即通关。
生命
共 3 条命，小球落到底部即扣 1 条，扣完游戏结束。
计分
每块砖 10 分；越靠上的砖块颜色越冷，分数相同但更难触及。
反弹角度
小球击中挡板的位置越靠边，反弹角度越斜，可用于主动控制落点。
加速
每击碎 8 块砖小球略微提速，最高 1.6×。

上手技巧

用边缘接球
用挡板两侧接球可打出更斜的角度，更容易打到侧边砖块。
避免垂直对撞
正中接球会让球垂直往返，反而难以清掉两侧砖块。
提前预判
小球提速后要提前移动挡板，避免来不及反应。

常见问题

一共有几条命？

共 3 条命。小球落到底部扣 1 条命并重新发射，3 条用完后本局结束。

怎样控制小球的反弹角度？

用挡板的不同位置接球即可改变角度：击中的位置越靠近挡板两端，反弹越斜；正中接球则接近垂直往返，反而不利于清理两侧砖块。

小球会越来越快吗？

会逐步提速：每击碎 8 块砖小球略微加速，最高为初始速度的 1.6×。
